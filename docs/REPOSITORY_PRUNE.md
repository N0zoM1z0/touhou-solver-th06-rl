# Retired architecture

The active tree intentionally excludes:

- reconstructed/headless gameplay as training authority;
- mandatory ECL/source forecasting and source-complete admission;
- per-stage or per-pattern policy branches;
- Generation-1 through Generation-7 fitted learners, OPE, candidate wrappers,
  and native rankers whose action-relative benefit was not established;
- hand-designed action abstraction before dense episode linkage is validated.

The architecture discussion also leaves the following proposals inactive:

- a first-HIT-terminal survival critic as the initial task objective;
- a recurrent object encoder, ensemble lower-confidence scorer, or simultaneous
  IQL/CQL sweep before transparent supervised baselines;
- uncertainty-guided collection before a fixed uniform batch identifies a
  measured support failure;
- learned future-birth MPC before factual prediction succeeds while the simpler
  value baseline fails;
- SABER-style Wine branch acquisition before serial exact-prefix factual and
  input-delivery replayability is proven.

These are candidate hypotheses recorded in `paper/main.tex`, not hidden active
architecture. Restore or implement at most one after its named admission gate.

Git history preserves those experiments. Do not restore them into the runtime
or training path without a new predeclared experiment showing why the minimal
system cannot answer the research question.

The retained active surface is original-Wine setup/control, coherent physical
capture, observed-hazard geometry, immutable corpus storage/audit, a generic
episode loader, reactive smoke policy, and uniform shield exploration.
