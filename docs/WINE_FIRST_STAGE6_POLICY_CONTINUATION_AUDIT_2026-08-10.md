# Stage 6 frozen-UCB source continuation audit (2026-08-10)

## Decision

Frozen-UCB decision state can be restored at an exact original-retail Wine
checkpoint and advanced faithfully inside reconstructed source COW for the
tested late Stage 6 prefix. This clears an infrastructure prerequisite for a
small policy-faithful counterfactual experiment. It does not create a policy

natural original-retail Wine Stage 6 runs against frozen UCB, ultimately with
repeatable 0-HIT clears. Full-Stage HIT continuation remains evaluation-only
and cannot enter fitting.

## Evidence boundary and next experiment

This is a factual-path equivalence result for one locally matched Wine prefix,
not a declaration that source and retail are globally equivalent. The known
dialogue hazard-count gap and Linux/MinGW numeric drift remain real.

The next experiment may therefore use this same fixed r5 checkpoint to replace
one native-safe first action, then let the restored immutable frozen UCB policy
own every later decision. Selection rules, action set, branch horizon, and an
independent r6 confirmation must be committed before any counterfactual result
is observed. A source winner remains a headless hypothesis only and must pass
new disjoint original-retail Wine shadow evidence before activation.
